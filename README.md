# GitProject

Bài tập sử dụng Git và GitHub của khóa HTML & CSS.

Repository được tạo trên GitHub, clone về máy, sau đó thêm README và mã nguồn bằng hai commit riêng.

## Các lệnh chính

- `git clone URL`: tải repository, lịch sử và thiết lập remote origin.
- `git add README.md`: đưa README vào staging.
- `git commit -m "Add README.md"`: ghi nhận thay đổi README.
- `git push origin main`: đẩy nhánh main lên GitHub.
- `git add source/`: đưa các file HTML vào staging.
- `git commit -m "Add source files"`: ghi nhận mã nguồn mới.

## Cấu trúc

```text
GitProject/
├── README.md
└── source/
    ├── index.html
    └── news.html
```

Mở `source/index.html` để xem trang chính và điều hướng đến trang tin tức.
